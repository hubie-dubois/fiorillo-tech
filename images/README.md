# Fiorillo Tech Image Assets

## Folder layout

- `brand/`: Fiorillo Tech logo, reverse logo, square mark, and social preview image.
- `photos/`: site photography.
- Browser-discovery icons live at the site root: `favicon.ico`, `favicon.svg`, favicon PNGs, `apple-touch-icon.png`, and `site.webmanifest`.

## Brand files

- `brand/fiorillo-tech-logo.svg`: primary horizontal logo on a transparent background.
- `brand/fiorillo-tech-logo-reverse.svg`: horizontal logo for dark backgrounds.
- `brand/fiorillo-tech-mark.svg`: square icon/brand mark for avatars and compact placements.
- `brand/fiorillo-tech-logo-preview.png`: social preview image of the primary SVG.

## Colors

- Ink: `#171717`
- Garnet: `#8A1F2D`
- Brass: `#C18B2F`
- Paper: `#F7F3EA`
- Warm gray: `#4E4A43`

## HTML

```html
<link rel="icon" href="favicon.svg" type="image/svg+xml">
<link rel="icon" href="favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="apple-touch-icon.png">
```
